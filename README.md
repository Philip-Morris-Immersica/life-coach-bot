# Life Coach Bot 🧭

Личен AI коуч за **навици, вярвания и идентичност** — Telegram бот, който те търси
сам (проактивни check-in-и сутрин/вечер), помни всичко (Neon/Postgres) и може да
влиза в дълбоки коучинг сесии.

Стек: **Node + TypeScript + Telegraf + OpenAI + Neon (Drizzle ORM)**.

---

## Какво прави

- **Опознавателна сесия** при първо `/start` — води интервю за идентичност, вярвания,
  история, навици и проблеми, после структурира всичко и поставя ясни цели.
- **Всекидневен режим** — кратки, подкрепящи отговори; усети ли по-дълбок проблем,
  предлага дълбока сесия.
- **Дълбоки сесии** (`/deep`) — Сократов диалог; извлича и запазва "прозрение" накрая.
- **Проактивни напомняния** — сутрешен фокус и вечерна рефлексия (node-cron).
- **Памет** — профил, навици, цялата история на разговорите и прозренията в Neon.

## Памет (таблици)

`users`, `profiles`, `habits`, `check_ins`, `messages`, `insights`.

## Настройка (еднократно, ~5 мин)

Трябват ти 3 неща в `.env` (вече има създаден `.env` файл за попълване):

### 1. `TELEGRAM_BOT_TOKEN`
В Telegram пиши на **@BotFather** → `/newbot` → следвай стъпките → копирай токена.

### 2. `OPENAI_API_KEY`
Твоят OpenAI ключ. Моделите се задават с `OPENAI_MODEL_FAST` (кратко, по подразбиране
`gpt-4o-mini`) и `OPENAI_MODEL_DEEP` (дълбоко, по подразбиране `gpt-4o`).

### 3. `DATABASE_URL`
Създай **нов** Neon проект (отделен от другите ти проекти) на https://neon.tech →
вземи connection string-а (с `?sslmode=require`).

### Създаване на таблиците

След като попълниш `.env`:

```bash
npm run db:push
```

---

## Стартиране

```bash
npm start        # стартира бота
npm run dev      # стартира с auto-restart при промени
```

После в Telegram намери бота си и натисни **Start**.

---

## Качване онлайн (за да работи 24/7)

За да те търси ботът дори когато компютърът ти е изключен, качи го на безплатен хостинг
(Railway.app или Render.com):

- Команда за стартиране: `npm start`
- Добави същите environment променливи (от `.env`)
- `TIMEZONE` контролира часовете на напомнянията (по подразбиране `Europe/Sofia`)

## Команди в бота

| Команда | Действие |
|---|---|
| `/start` | Първо посрещане / опознавателна сесия |
| `/deep` | Започни дълбока коучинг сесия |
| `/end` | Приключи дълбоката сесия (запазва прозрение) |
| `/habits` | Покажи активните навици |
| `/checkins on\|off` | Включи/изключи проактивните напомняния |
| `/reset` | Започни опознаването наново |
